# ContextPilot 0.2 / Bağımlılık ve token odaklı bağlam

0.2 aynı yerel CLI ve Codex becerisini genişletir. Yeni servis, API anahtarı veya farklı bir proje gerektirmez.

## 1. Bağımlılık ve test seçimi

```sh
contextpilot pack "schedule_dispatch" --root ./app --with-dependencies --max-chars 8000 --max-files 6
contextpilot graph --root ./app --path app/service.py
```

Önce eşleşen üretim kodundan başlangıç dosyaları seçilir. Sonra bu dosyaların bir adımlık yerel bağımlılıkları ve seçilen bağlama import ile bağlanan testler eklenir. Başlangıç kodu, bağımlılık, test ve diğer eşleşmeler farklı karakter payları alır. Toplam bütçe her durumda korunur; küçük bütçede bütün bağlantıların gelmesi garanti edilmez.

| Dil | Yöntem | Bilinen sınır |
|---|---|---|
| Python | AST üzerinden import / relative import | Dinamik import ve çalışma zamanı module path değişimleri yok |
| JS / TS | Göreli import, require ve re-export metinleri | Path alias ve package çözümleme yok; yorumlar yanıltabilir |
| Dart | Yerel göreli import | `package:` ve SDK import çözümleme yok |
| C# | Depoda tekil sınıf / arayüz / record adı bağlantısı | Tam namespace / overload / semantic çözümleme değildir |

Grafik yalnızca daha önce güvenlik filtresinden geçen kaynakları içerir. Gizli veya ignore edilmiş dosya, import edildi diye pakete eklenmez. Döngüler sonsuz genişlemeye yol açmaz. `Selection` etiketleri her dosyanın neden seçildiğini gösterir.

## 2. İsteğe bağlı gerçek encoding sayımı

```sh
python -m pip install ".[tokenizer]"
contextpilot count example.txt --encoding o200k_base
contextpilot pack "schedule_dispatch" --root ./app --with-dependencies --encoding o200k_base --max-tokens 2000 --max-chars 8000 --json
```

Desteklenen açık encoding adları: `o200k_base`, `cl100k_base`, `p50k_base`. `--max-tokens` yalnızca encoding verilirse kabul edilir. Tokenizer yoksa işlem açık hata verir; tahmini sayıya sessizce dönmez. Etiketler ve uyarılar da paket bütçesine dahildir. Çok düşük bir bütçe zorunlu etiketleri bile taşımıyorsa hata verilir.

Varsayılan kurulum hâlâ Python standart kitaplığıyla çalışır. Tokenizer ekstra paketi `tiktoken==0.12.0` kullanır. Encoding tabloları ilk kullanımda indirilebilir; çevrimdışı kullanım için `TIKTOKEN_CACHE_DIR` önceden hazırlanmalıdır. Kaynak kod veya soru uzak bir modele gönderilmez.

**Ölçüm sınırı:** Sayı, seçilmiş encoding altında düz metin için kesindir. Aktif Codex modelinin encoding'i varsayılmaz. Mesaj rolleri, araç tanımları, gizli bağlam, akıl yürütme ve cevaplar buna dahil değildir. [OpenAI token sayımı açıklaması](https://developers.openai.com/api/docs/guides/token-counting) da yerel tokenizer ile tam istek sayımını ayırır.

Paketlenmiş kaynak normalize edilir ve bilinen gizli bilgi biçimleri maskelenir. `count` komutu da normalize / maskelenmiş metni sayar; ham dosya baytlarının sayımı değildir. Rapor, tahmini UTF-8 ölçüsünü ve varsa gerçek encoding sayımını ayrı alanlarda tutar.

## 3. Aynı sohbete ait onaylı değişiklik paketleri

```sh
contextpilot session-start chat-upload-01 --root ./app
contextpilot pack "compute_total" --root ./app --session chat-upload-01 --json
# Paket gerçekten ve kesilmeden okunduktan sonra, rapordaki receipt ile:
contextpilot ack chat-upload-01 RECEIPT --root ./app
# Aynı sohbet içinde sonraki okuma:
contextpilot pack "compute_total" --root ./app --session chat-upload-01 --json
```

- İlk paket kaynak kesitini gönderir; paket üretmek tek başına onay sayılmaz.
- Yalnızca **tamamı gösterilmiş** dosya onaylı temel olabilir. Kısmi pencere hiçbir zaman dosyanın geri kalanını gizlemez.
- Onaylı tam dosya değişmemişse kısa referans, değişmişse onaylı metne göre unified diff sunulabilir.
- Diff bütçeye sığmazsa güncel kesit gönderilir; kısmi diff, tam temel gibi onaylanmaz.
- Yeni bir paket önceki bekleyen receipt'i geçersiz kılar. Süresi dolmuş veya bozulmuş durum dosyası reddedilir.
- Süre dört saattir. En fazla 100 tam dosya ve 8 milyon karakter tutulur. Oturum klasörü yerel, açık metindir; şifreli kasa değildir.
- Aynı session id için tek yazıcı kullanılmalıdır; süreçler arasında dağıtık kilit sağlanmaz.

**Yeni sohbet, bağlam sıkıştırması veya daha önceki paketin hatırlandığından emin olunmayan durumda yeni id aç.** Program modelin gerçek hafızasını okuyamaz; bu sözleşme açık kullanıcı / ajan onayına dayanır. Kesilmiş araç çıktısını onaylama.

## 4. Aynı bütçeyle karşılaştırma

```sh
contextpilot compare "schedule_dispatch" --root ./app --max-chars 6000 --max-files 4 --expected-file app/policy.py --evidence "return zone in" --encoding o200k_base
python scripts/paired_benchmark.py --encoding o200k_base
```

İki yöntem aynı kaynak ve karakter bütçesiyle çalışır. Rapor; beklenen dosya / işaretlerin bulunmasını, çıktı boyutunu ve seçilmiş encoding sayılarını yan yana verir. Gerekli dosyaları tanımlamazsan kanıt başarımı uydurulmaz; recall `null` olur.

Fixture'lar Python, TS, Dart ve C# için bir adımlık bağlantıları içerir. Ayrıca **iki adımlık bağımlılığın bulunamadığı bilinen sınır** da raporda saklanır. Daha fazla kanıt içeren paket, daha çok token kullanabilir; bu fark gizlenmez. Kod hatasını düzeltme başarısı, model çağrısı veya toplam abonelik kullanımı ölçülmez.

Ham rapor: [paired-benchmark.json](../examples/results/paired-benchmark.json). Okunabilir tablo: [paired-results.md](paired-results.md).

## 5. Var olan beceriyi güvenli güncelle

```sh
python scripts/install_skill.py --update --backup ./skill-backup-0.1
```

Kurulum manifestindeki sahipli dosyaların hash değerleri önce doğrulanır. Yerelde değiştirilmiş dosya veya yeni sürümle çakışan sahipsiz dosya varsa işlem durur. Önce sahipli dosyalar ve manifest yeni bir yedek dizinine kopyalanır. Dosya değiştirme sırasında hata olursa yazılan dosyalar geri alınır. Diğer beceriler ve genel Codex ayarları değiştirilmez.

Bu mekanizma dosya sistemiyle eşzamanlı kötü niyetli bir işlemi engelleyen güvenlik sandbox'ı değildir. Güncelleme sırasında aynı kuruluma başka işlem yazmamalıdır.
